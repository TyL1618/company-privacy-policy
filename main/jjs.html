隱私權保護政策

金救星重視每一位使用者的個人資料與隱私安全。為使您能安心使用本網站提供之各項服務， 特訂定本隱私權保護政策，說明資料蒐集、使用及保護方式，請您詳細閱讀以下內容。

一、政策適用說明

本政策適用於您使用金救星網站及相關服務時所涉及之個人資料蒐集、處理與利用行為。

若您透過本網站連結至其他第三方網站或服務，其隱私權保護措施將由該網站自行規範，與金救星無涉，建議您另行查閱其相關政策內容。

二、資料蒐集項目

為提供諮詢、聯繫及相關服務，當您主動填寫表單、留言或與我們聯繫時，我們可能蒐集以下資訊：

  • 姓名
  • 聯絡電話
  • 電子郵件信箱
  • LINE ID 或其他聯絡方式
  • 留言內容及諮詢需求
  • 與服務相關之互動時間與紀錄

上述資料僅限於提供服務、回覆問題及相關業務需求使用。

三、資料使用原則

您所提供之個人資料，將於蒐集目的範圍內進行處理與利用，未經您的同意，除法令另有規定外，不會作為其他用途。

如服務需求已結束或資料已無保存必要，我們將依合理期間保存後進行刪除或去識別化處理，以維護您的個人資料安全。

四、資訊安全措施

金救星採取適當之管理及安全措施，以避免個人資料遭未經授權之存取、竄改、洩漏或毀損。

僅經授權之相關人員得於必要範圍內接觸資料，並應遵守保密義務及相關規定。

五、第三方資料提供

金救星不會將您的個人資料出售、交換、出租或提供予任何第三人。但有下列情形者，不在此限：

  1. 已取得您的明確同意。
  2. 依法律規定或主管機關要求辦理。
  3. 為維護公共利益或保障使用者權益所必要。
  4. 因配合司法機關、行政機關或其他依法有權機關之調查需求。
  5. 為防止違法行為或保障網站及相關使用者之合法權益。

六、使用者權利

依據個人資料保護法規定，您得就本人資料行使以下權利：

  • 查詢或請求閱覽。
  • 請求製給複製本。
  • 請求補充或更正。
  • 請求停止蒐集、處理或利用。
  • 請求刪除個人資料。

若有相關需求，可透過下列聯絡方式與我們聯繫。

七、政策更新

金救星保留隨時修訂本隱私權保護政策之權利，更新後之內容將公告於網站，不另行個別通知。
